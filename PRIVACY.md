# Privacy Policy

**Sculpture Plugin** — last updated 2026-03-31

## Summary

Sculpture collects no user data. Period.

## What Sculpture Does Not Do

- Does not collect, store, or transmit any personal data
- Does not phone home to any server
- Does not track usage, sessions, or behavior
- Does not send your prompts, responses, or sculpture specs anywhere

## What Stays on Your Machine

- `sculpture.yaml` — your agent's capability spec, stored locally in your project
- `sculpture-violations.log` — Wall 2 violation log, stored locally in your project
- Any audit reports generated by `tools/audit.py` — saved locally only

## Anthropic API

When you use `SculptedClient`, your messages are sent directly from your machine
to Anthropic's API using **your own API key**. Sculpture does not proxy, intercept,
or log these requests beyond the local violation log described above.

Anthropic's own privacy policy applies to those API calls:
https://www.anthropic.com/privacy
